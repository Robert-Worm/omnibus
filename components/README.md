# Interface-onderdelen (`components/`)

> **In het kort:** losse bouwblokken voor de schermen, zoals knoppen, tabbladen, tabellen en dialoogvensters. De schermen zelf staan in [`app/`](../app/README.md).

## Wat staat hier?

| Map | Wat erin staat |
| --- | --- |
| `ui/` | Basisonderdelen in de stijl van [shadcn/ui](https://ui.shadcn.com/): knop, invoerveld, tabblad, tabel, dialoog en meer |

## Spelregels

- Gebruik deze onderdelen in plaats van eigen varianten te maken.
- Kleuren en lettertypen komen uit de gedeelde stijl; voeg geen losse kleuren toe.
