# Bijdragen aan Omnibus

> **In het kort:** helpen kan op veel manieren. De belangrijkste is een bron verwerken; alle uitleg staat in de documentatie hieronder.

Fijn dat je wilt helpen! Alles over meedoen staat in de documentatie:

| Je wilt… | Lees |
| --- | --- |
| Een rapport, wet of kader verwerken | [Meedoen](docs/bijdragen/README.md) en [een bron verwerken](docs/bijdragen/bron-verwerken.md) |
| Zien wat er nog open staat | [Voortgang](docs/bijdragen/voortgang.md) |
| De code verbeteren | [Ontwikkelen](docs/bijdragen/ontwikkelen.md) |
| Een fout melden of iets voorstellen | [Issues](https://github.com/Robert-Worm/omnibus/issues/new/choose) of [Discussions](https://github.com/Robert-Worm/omnibus/discussions) |

## Kort de belangrijkste afspraken

- **Geen vertrouwelijk materiaal** in issues, reacties of pull requests: geen interne documenten, persoonsgegevens, databases of wachtwoorden.
- **Klein en gericht.** Eén onderwerp per pull request. Grotere wijzigingen eerst bespreken.
- **Eerlijk over wat je hebt getest.** Beschrijf welke tests je hebt gedraaid, en wat niet.
- **Respectvol.** Zie de [gedragscode](CODE_OF_CONDUCT.md).
- **Beveiligingsproblemen** meld je vertrouwelijk, zie [SECURITY.md](SECURITY.md).
